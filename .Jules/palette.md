## 2024-05-18 - Telegram Keyboard UX & Emojis
**Learning:** Adding emojis to Telegram custom keyboards improves scannability and visual appeal, but it breaks strict equivalence checks (`==`) and regex filters like `Filters.regex('^(Yes|No)$')` because the input string now contains the emoji character along with the text. Furthermore, using `resize_keyboard=True` is a critical usability win for Telegram bots, as it ensures keyboards are properly scaled down on mobile devices and don't occupy unnecessary screen real estate.
**Action:** Always include `resize_keyboard=True` on `ReplyKeyboardMarkup` instantiations for optimal mobile display. When supporting emoji-prefixed strings, rely on partial matching like `if 'yes' in user_choice:` within handler callbacks and use broad text matchers like `Filters.text & ~Filters.command` in `ConversationHandler` definitions rather than strict regex.
