## 2024-07-09 - Telegram Custom Keyboard Optimization
**Learning:** Default Telegram custom keyboards (`ReplyKeyboardMarkup`) can take up too much vertical screen space on mobile devices and feel unpolished if buttons are presented as a single wide list. Furthermore, adding visual cues like emojis to button labels requires careful handling of string comparisons on the backend to avoid breaking command logic.
**Action:** Always set `resize_keyboard=True` to adapt the keyboard height dynamically for mobile users. Structure buttons into logical grids (e.g., 2x2) rather than a single column to improve scannability and save space. When adding emojis to labels for visual delight, use the `in` operator (e.g., `if 'buy number' in user_choice`) rather than exact matching to ensure robustness.
