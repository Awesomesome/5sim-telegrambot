## 2026-09-16 - Custom Keyboard UX Optimization
**Learning:** Telegram custom keyboards can be overwhelming and hard to use on mobile devices if they consist of long, single-column lists. Emojis added by users can also break strict string matching.
**Action:** When creating or modifying `ReplyKeyboardMarkup`, always use `resize_keyboard=True` for mobile optimization. Organize buttons into logical grids, specifically chunking long single-column lists into multi-column grids (e.g., using `chunk_list(lst, 2)`) to prevent excessive scrolling. When handling user input for options that might include text alongside emojis, prefer using partial string matching like `.startswith()` instead of strict equivalence (`==`), and sort options by length descending if they can overlap to prevent unintended partial matches.
