## 2026-07-21 - Telegram Mobile Keyboard UX & Emoji Input Support
**Learning:** Custom Telegram keyboards without `resize_keyboard=True` appear disproportionately large on mobile devices, taking up valuable screen space and diminishing the user experience. Furthermore, single-row layouts with multiple buttons become cramped and illegible. Additionally, when emojis are added to keyboard buttons for visual flair, users often reply with the text *and* the emoji. Strict string matching or regex validation (e.g., `Filters.regex('^(Yes|No)$')` or `user_choice == 'buy number'`) fails when emojis are present, causing a frustrating UX where valid intents are rejected.

**Action:** Always set `resize_keyboard=True` when creating `ReplyKeyboardMarkup` in Telegram bots to optimize for mobile. Organize multiple buttons into logical grid structures (e.g., 2x2) rather than single wide rows. To handle text input robustly alongside emojis, use `Filters.text & ~Filters.command` in `ConversationHandler` states instead of strict regex, and parse user intent by checking if keywords exist within the input string (e.g., using the `in` operator like `'yes' in text.lower()`).
